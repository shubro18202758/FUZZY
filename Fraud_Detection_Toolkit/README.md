# Fraud Detection & Anomaly Detection Toolkit 🕵️‍♂️💳

Welcome to the **Fraud Detection Toolkit**. This repository contains a comprehensive guide to the industry-standard technologies, mathematical foundations, and advanced techniques used to detect fraud and anomalies in financial datasets.

This toolkit is designed for students, researchers, and practitioners who want to master the domain of financial fraud detection using Python and Machine Learning.

## 📚 Table of Contents

1.  **[Advanced Python Libraries](./01_Advanced_Python_Libraries.md)**
    *   Explore the essential and advanced libraries used in the industry, from data manipulation to specialized anomaly detection toolkits.
2.  **[Feature Engineering Techniques](./02_Feature_Engineering_Techniques.md)**
    *   Learn how to transform raw transaction data into powerful signals that models can learn from (Velocity, Aggregations, Time-based features).
3.  **[Mathematical & Statistical Foundations](./03_Math_and_Stats_Foundations.md)**
    *   Dive into the math behind the magic: Probability distributions, Benford's Law, Z-Scores, and Distance metrics.
4.  **[Anomaly Detection Algorithms](./04_Anomaly_Detection_Algorithms.md)**
    *   A deep dive into algorithms ranging from statistical methods (Isolation Forest, LOF) to Deep Learning (Autoencoders, GANs).
5.  **[Evaluation & Validation](./05_Evaluation_and_Validation.md)**
    *   How to properly evaluate models on highly imbalanced datasets using Precision-Recall, ROC-AUC, and Cost-Sensitive learning.
